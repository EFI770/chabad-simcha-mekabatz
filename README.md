# מקבץ מקורות חב\"ד על מעלת השמחה

מקבץ מסודר של מקורות חב\"ד אותנטיים על מעלת השמחה + **אפליקציה לשיתוף בוואטסאפ**.

## אפליקציה (סטטית)

תיקייה `app/` — דף HTML פשוט + `stories.json`:
- חיפוש וסינון לפי תגיות (כולל **ברית מילה**)
- כפתור **שליחה בוואטסאפ** לכל סיפור
- כפתור **העתקה** ללוח

### הפעלה מקומית
פתח את `app/index.html` בדפדפן, או הגש עם שרת סטטי.

### GitHub Pages
אפשר להפעיל Pages מהענף `main` עם תיקיית `/app` (או root אם מעבירים את הקבצים).

כתובת ה-repo: https://github.com/EFI770/chabad-simcha-mekabatz

## קבצים
- `mekabatz-simcha.md` — מקבץ עם קישורים לתורת מנחם, אגרות, ספר השיחות, אוצר סיפורי חב\"ד
- `sipurim-simcha.md` — סיפורים נרטיביים
- `app/` — האפליקציה

## מקורות מומלצים להרחבה
- תורת מנחם (HebrewBooks)
- ספר השיחות של הריי\"צ
- לקוטי דיבורים
- אגרות קודש (ריי\"צ והרבי)
- אוצר סיפורי חב\"ד (גליצנשטיין)
- ספר הזכרונות של הריי\"צ
